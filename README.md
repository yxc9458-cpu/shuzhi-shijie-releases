# 剧好玩・数智视界发布仓库

此仓库只用于发布“剧好玩・数智视界”Windows 安装包和自动更新清单，不存放用户项目、API Key、缓存或调试数据。

## 下载

请在右侧 **Releases** 中下载最新的 `SoulLens-Setup-<版本>.exe`。

## 更新通道

- `dev.yml`：当前开发版通道。
- `release.json`：版本说明、最低支持版本和强制更新策略。
- `*.blockmap`：后续增量更新预留文件；当前 Windows 客户端仍下载完整安装器。

## 安全说明

客户端在安装前会校验更新清单中的 SHA-512。正式大规模分发前，建议为安装器增加 Windows 代码签名。
